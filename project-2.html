LLM-Based Agent for Automated Weather Disaster Management

This project introduces an LLM-based agent for weather disaster management, built using LangGraph. The system integrates a specialized machine learning model for wildfire prediction with a large language model that analyzes other threats like floods and storms.

By processing real-time weather data, the agent assesses the disaster type and severity level to automatically generate tailored response plans and issue multi-modal alerts, including detailed emails and text-to-speech audio reports.
